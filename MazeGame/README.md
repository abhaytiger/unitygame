# GyroMaze 3D - Professional Unity Maze Game

A professional-grade 3D maze game built for **Unity 2022+** with gyroscope controls, procedural generation, and 10 unique visual themes across 100 levels.

## Features

### Core Gameplay
- **100 Unique Levels** - Procedurally generated mazes with progressive difficulty
- **Gyroscope Controls** - Tilt your device to roll the ball (mobile)
- **Keyboard/Mouse Fallback** - WASD/Arrow keys for desktop testing
- **Touch Joystick** - On-screen virtual joystick alternative
- **Smooth Camera Follow** - Orbit controls with pinch-to-zoom

### Visual Themes (10 Total)
Every 10 levels unlocks a new theme:
1. **Classic Steel** (Levels 1-10)
2. **Neon City** (11-20)
3. **Ancient Stone** (21-30)
4. **Ice Palace** (31-40)
5. **Lava Factory** (41-50)
6. **Crystal Cavern** (51-60)
7. **Forest Temple** (61-70)
8. **Space Station** (71-80)
9. **Shadow Realm** (81-90)
10. **Divine Paradise** (91-100)

## Quick Start

1. Push this folder to GitHub
2. Clone on your PC
3. Open with Unity Hub (Unity 2022.3+ required)
4. Create scene with GameManager, MazeGenerator, Ball, and CameraFollow components
5. Press Play!

## Controls
- **Desktop**: WASD/Arrows to move, Right-click to orbit camera, Scroll to zoom
- **Mobile**: Tilt device (gyro), Touch drag to orbit, Pinch to zoom

Full documentation in project files.
